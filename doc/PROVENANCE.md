# 제작·선정 근거

사용자가 2026-11-04 현재 첨부 검수안을 최종 패키징하도록 요청했다. 첨부 정본은 2026-11-03T21:12:07.925Z, 이미 반영된 검수 기록과 SHA 동일하다. 현재 이미지·음원·게인·조립 지문에 연결된 좋음 440건만 수록했다. 미검수/보완/수정 후 미재검수는 자동 승격하지 않았다.

이미지는 pixFX studio의 검수된 procedural 픽셀 RGBA를 추출했다. native 128인 항목은 검수 화면과 같은 nearest 3배로 384 출력. 7개 반복 합성은 모든 구성 요소 프레임 전환 시각의 합집합을 가변 프레임 시계로 보존했다. 원래 파일과 의미 사건 시계를 바꾸지 않는다.

음원은 Grok 영상의 오디오와 그 원음으로 만든 기존 조합에서, 사용자 자름·페이드·시작·게인을 기준으로 추출했다. 새 생성 호출은 없다. 페이드만 WAV에 적용하고 게인은 조합에 남긴다. 48kHz 가장 가까운 샘플로 자름/시작을 양자화하므로 오차는 최대 약 0.0105ms, PCM16 재양자화는 최대 0.5 LSB다. fade envelope는 기존 WebAudio 33-point sin/cos 선형보간을 따른다. 메인음/피크 분석은 신호 가설이며 청취로 확정한 본질을 뜻하지 않는다.

키워드 정규화→압축 검색 색인→개별 사용 메타데이터의 구조는 [OPEN-RPGBGM](https://github.com/vetyj2/open-RPGBGM)의 공개 README·AGENTS·doc 구성을 참고했다. 해당 저장소의 오디오·이미지·코드를 복사하지 않았다. 본 패키지에는 별도의 타격/본음·연타 간격·잔향·강도 및 재사용 금지 문맥을 적용한다.

메타데이터 근거가 부족한 충돌은 candidate로 표시한다. 시트량/밝기 피크를 물리 충돌로 바꾸지 않는다. 프롬프트는 SHA로 연결되는 기록만 실제 원문으로 싣고 나머지는 용도 키워드로 구분한다. 패키지 이름에서 배포 라이선스를 추정하지 않는다.
